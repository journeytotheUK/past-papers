Kaise use karein

Is guide mein aap ke 7 subjects ke past-paper files ke links hain — Moaaz, Waqar Siddhu, Junaid aur Arslan ki files. Har row mein likha hai ke file kis website par hai, kis ne banayi hai, midterm hai ya finalterm, MCQs hain ya subjective, aur link khud khol kar check kiya gaya hai ya nahi.

Sab se ahem baat — ye official papers nahi hain

Ye files students ne banayi hain (Moaaz, Waqar, Junaid, Arslan) — ye VU ke official past papers nahi hain. In mein jawab ghalat bhi ho sakte hain, aur hum ne pehle se ghalat jawab dhoonde bhi hain:

  • CS621 ki aik file mein likha tha ke "multiple machines can process the same function at the same time" = Scalability — ghalat hai, ye Concurrency hai.
  • CS609 ke aik hal mein likha tha ke C/C++ heap mein garbage collection hoti hai — ghalat hai, heap mein garbage collection nahi hoti.
  • MTH501 ki Junaid file mein likha hai ke 5-dim space ka spanning set "at most five elements" ka hona chahiye — ghalat hai, kam se kam 5 elements chahiye.

Is liye: file ka jawab andha dhund na yaad karein — handout se check karein. Aur agar kisi sawal ka hal chahiye to neeche wale prompts use karein: main hal kar ke doon gi aur file ke hal se compare kar ke bataoon gi ke file ka hal sahi hai ya ghalat.

Link kaise kholein? Table mein "Link" wale button par click karein — woh us listing page par le jaye ga jis par file hai. Google Drive ki files seedha link nahi ki gayi hain: listing page par DOWNLOAD button dabayein, woh aap ko Drive file tak le jaye ga. Ye jaan boojh kar aisa kiya gaya hai, taake koi ghalat Drive link na di jaye.

Mera waada

Solve karne ka waada

Jab aap kisi file ka link aur prompt is main chat mein dein gi, to main ye karoon gi:

1. Step-by-step hal — sawal ko aasan Roman Urdu mein, step by step solve kar ke doon gi, aise ke samajh aaye ke jawab kyun wohi hai.

2. File ke hal se compare — agar file mein us sawal ka hal pehle se likha hai, to main apna hal us se compare karoon gi aur saaf bataoon gi ke file ka hal sahi hai ya ghalat, aur kyun ghalat hai.

3. Ghaltiyan flag karna — agar file mein ghalat jawab, ghalat formula ya ghalat tareeqa hai, to woh point out karoon gi aur sahi tareeqa handout ke mutabiq bataoon gi.

4. Naye sawal banana — aap ke kehne par usi file / topic se naye MCQs (10, har aik ke 4 options + wajah) ya subjective sawal (2, 3 aur 5 marks, model answer ke saath) bana kar doon gi — file ke sawalon jaise, lekin copy nahi.

Ek shart

Prompt is main chat mein dein — kisi doosri chat mein nahi. Isi liye har prompt box ke saath ye note likha hai. Aur agar file ka link Drive ka hai to listing page ka link dein (jis par DOWNLOAD button hai), taake main file tak pahunch sakoon.
